📍 Map File Manager（マップ・ファイル・マネージャー）

noteにて画像付きの操作説明を掲載しています。
https://editor.note.com/notes/n4a1e7ecfea46/edit/

地図上の好きな場所にピンを立てて、その場所に関連するファイルやメモを紐づけて管理できる、ローカル動作のデスクトップアプリです。

「あの旅行先の写真、どこに保存したっけ」「この土地の資料、どこに置いたっけ」を、**地図上の位置そのものをフォルダ代わりにして**管理できます。

## ✨ 主な機能

- 🗺️ 地図をクリックするだけでピン（地点）を作成
- 📁 ピンごとに専用フォルダを自動生成し、ファイルをドラッグ＆ドロップで格納
- 🏷️ ピンの名前変更・色分け・位置変更
- 🔍 登録済みピンの名前検索・並び替え（50音順／作成日／更新日）
- 🌍 地名・駅名からの地図検索
- 📤 選択したピンをZIPファイルとしてエクスポート
- 📥 ZIPファイルから他のPCへピンとファイルをインポート
- 💻 完全にローカルで動作（データは自分のPC内のみに保存）

## 🖥️ 必要環境

- Node.js 18 以上
- Windows / macOS / Linux

## 🚀 セットアップ

```bash
git clone https://github.com/yourname/mapfileman.git
cd mapfileman
npm install
npm start
```

`npm install` の際に、地図表示ライブラリ（Leaflet）とZIP処理ライブラリ（JSZip）もローカルに取得されます。以降はインターネット接続なしでもアプリ本体は起動できます（地図タイル・地名検索を除く。後述）。

## 📖 使い方

noteにて説明しています。
https://editor.note.com/notes/n4a1e7ecfea46/edit/

1. 地図上の好きな場所をクリックすると、その場所にピンが作成されます
2. 作成したピンをクリックすると、右側にファイル管理パネルが開きます
3. パネル内の「➕ 追加」でファイルを選択、または画面に直接ドラッグ＆ドロップして格納できます
4. 「⚙️ ピンの設定」から、名前の変更・色の変更・位置の変更・削除が行えます
5. 左上の「📋 ピン一覧」から、登録済みのピンを検索・並び替えて一覧表示できます

## 💾 データの保存場所

ピンの情報とファイルは、OSの標準的なアプリデータ領域に保存されます。

| OS | 保存先 |
|---|---|
| Windows | `%APPDATA%\mapfileman\MapPinsData` |
| macOS | `~/Library/Application Support/mapfileman/MapPinsData` |
| Linux | `~/.config/mapfileman/MapPinsData` |

アプリをアンインストールしてもこのフォルダは自動削除されないため、必要に応じて手動で削除してください。

## 📤 エクスポート / 📥 インポート

- **エクスポート**：左パネルの「📤 エクスポート」を押すと、書き出したいピンを選択するダイアログが開きます。選択後、保存先を指定するとZIPファイルが作成されます
- **インポート**：「📥 インポート」から他のPCで作成されたZIPファイルを選択すると、取り込むピンを選べる確認画面が表示されます

これを使うと、**個人のPC間でのデータ移行**や、**コミュニティ内でのピン共有**（USBメモリやファイル共有サービス経由でZIPを渡すなど）が可能です。

## 🌐 利用している外部サービスについて

本アプリは、地図表示と地名検索のために以下の無料公開サービスを利用しています。それ以外のライブラリ・画像はすべてアプリに同梱されており、外部通信は発生しません。

| サービス | 用途 | 利用ポリシー |
|---|---|---|
| [OpenStreetMap](https://www.openstreetmap.org/) タイルサーバー | 地図の背景表示 | [Tile Usage Policy](https://operations.osmfoundation.org/policies/tiles/) |
| [Nominatim](https://nominatim.org/) | 地名・駅名からの位置検索 | [Usage Policy](https://operations.osmfoundation.org/policies/nominatim/)（1秒あたり1リクエストを遵守） |

本アプリは「個人または小規模コミュニティが、各自のローカルPCで利用する」ことを前提としています。**同じネットワーク内で多人数が同時に使う場合など、アクセスが集中する使い方は避けてください。**サーバーを立てて不特定多数に配信するような用途は想定していません。

## 🔒 セキュリティについて

- インポートするZIPファイルは、展開先が意図したフォルダの外に出ないよう検証しています（Zip Slip対策）
- ファイル名・フォルダ名に使用できない文字（`/` `\` `..` など）は作成・変更時に弾かれます
- Electronの推奨設定（`contextIsolation` / `sandbox` / CSPによる通信制限）を有効にしています

とはいえ、無保証のOSSです。重要なデータは別途バックアップを取ることを推奨します。

## 📦 配布用パッケージ（インストーラー）の作成

開発者向けに、`npm start` でソースから起動する以外に、**ダブルクリックだけで使えるインストール用ファイル**（Windowsの `.exe`、macOSの `.dmg`、Linuxの `.AppImage`）を作成できます。`electron-builder` を利用しています。

```bash
npm run dist:win     # Windows用 .exe（NSISインストーラー）を作成
npm run dist:mac     # macOS用 .dmg を作成（macOS上でのみ実行可能）
npm run dist:linux   # Linux用 .AppImage を作成
npm run dist         # 上記3つをまとめて作成（対応OS上でのみ）
```

生成物は `dist/` フォルダに出力されます。

**注意**：`package.json` の `build` 設定はアイコンファイル（`assets/icon.ico` / `assets/icon.icns` / `assets/icon.png`）を参照しています。実際にビルドする前に、これらのアイコンファイルを用意して `assets/` フォルダに配置するか、`build` 設定から該当の `icon` の行を削除してください（未設定の場合はElectronの既定アイコンが使われます）。

配布した `.exe` / `.dmg` に**コード署名をしていない場合**、Windowsでは「WindowsによってPCが保護されました」というSmartScreenの警告、macOSでは「開発元が未確認のため開けません」という警告がユーザー側に表示されます。無償の個人配布ではよくあることですが、README等に「詳細情報 → 実行」で起動できる旨を書き添えておくと親切です。コード署名証明書（年間数万円程度）を取得すれば警告は出なくなりますが、個人・小規模配布では必須ではありません。
